# Code of conduct

The LocoMuJoCo project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to everyone who takes part in the project: in the issue tracker, in
pull requests and reviews, and in any other space where the project is discussed or represented.

In short: be respectful, assume good intent, give and accept constructive feedback, and do not harass or
demean anyone. The full text behind the link above is the authoritative version.

## Reporting

If you experience or witness behaviour that violates the code of conduct, report it to the project
maintainers through the [GitHub repository](https://github.com/robfiras/loco-mujoco). The maintainers are
listed on the repository page and can be contacted through their GitHub profiles; you do not have to open
a public issue. Reports are handled confidentially, and the maintainers follow the enforcement guidelines
of the Contributor Covenant when deciding how to respond.
