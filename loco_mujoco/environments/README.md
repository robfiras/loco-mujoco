# LocoMuJoCo environments

This package contains `LocoEnv`, the base class of all environments, and the humanoid robots,
(musculo-)skeletal human models and quadrupeds built on it.

The [environment gallery](https://loco-mujoco.readthedocs.io/en/latest/environments/index.html) lists every
embodiment with its observation space, action space, constructor options and available datasets.
[Adding a new robot](https://loco-mujoco.readthedocs.io/en/latest/user_guide/new_robot.html) explains how to add
your own.
