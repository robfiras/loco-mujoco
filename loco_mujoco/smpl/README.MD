# SMPL-based retargeting

This package retargets human motion to robots through the SMPL body model and transfers motion from one robot
to another. The robot configurations are in `robot_confs/`.

The documentation has moved to the website:

- [AMASS and SMPL setup](https://loco-mujoco.readthedocs.io/en/latest/getting_started/amass.html): installing the
  optional dependencies, the SMPL and MANO models and the AMASS dataset
- [Retargeting](https://loco-mujoco.readthedocs.io/en/latest/user_guide/retargeting.html): how the pipeline works
- [Adding a new robot](https://loco-mujoco.readthedocs.io/en/latest/user_guide/new_robot.html): writing a robot
  configuration and retargeting the datasets to it
